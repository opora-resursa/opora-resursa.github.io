# Опора ресурса — профилактика эмоционального выгорания

Одностраничное веб-приложение для специалистов помогающих профессий (врачей, психологов, педагогов и социальных работников): экспресс-самооценка состояния по 4 осям, каталог из 30 методик саморегуляции с интерактивными тренажёрами и личный трекер восстановления.

Все записи и результаты хранятся локально в браузере пользователя без отправки на сторонние серверы.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка для публикации

```bash
npm run build
```

Готовая статика собирается в папку `dist/` с относительными путями (`base: './'`), поэтому страница работает одинаково стабильно на `GitHub Pages`, при встраивании через `<iframe>` на сайт заказчика или при переносе в любую подпапку собственного домена.
